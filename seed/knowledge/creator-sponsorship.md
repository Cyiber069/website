# Creator sponsorship and discount codes

ACX Ebikes runs a creator sponsorship offer for people on TikTok, WhatsApp and Gmail.

How it works:
A creator asks for their own personal discount code, for example "I would like to make my discount code MACCA5".
The code gives £20 off all kits, bundles and batteries.
The creator puts the code in their bio.
The creator earns 5% commission on sales made with their code.

Codes are letters and numbers only, 3 to 30 of them, with no spaces or symbols.
One code per creator.
If someone wants a code but has not said what it should be, ask them what they want their code to be.
Never tell anyone a code is live until the shop has made it. The shop sends a message when the code is live.
