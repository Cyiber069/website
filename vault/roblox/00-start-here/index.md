# 00 Start Here

> This chapter explains how the Roblox playbook is organised, the retention principles behind every rule, and the order in which to build a game.

## What this workspace is

This is a playbook for agents building Roblox experiences in Roblox Studio with Luau. Its single goal is retention: players who enjoy the first session, come back the next day, and keep finding reasons to return. Every chapter is written as rules plus the reason each rule works, so you can adapt a rule when a game's genre does not fit the example.

## Ground rules

- Phone first. A large share of Roblox play happens on touch devices, so a design that only works with a keyboard is unfinished.
- The server decides. The client displays and requests; it never awards.
- Measure before tuning. Opinions about balance are cheap; a timing table or a funnel is evidence.
- Do not invent facts about the platform. If you are unsure an API exists, check the current Roblox documentation before using it.
